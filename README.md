# Apuntes de examen: Git, GitHub Actions y GitHub Pages

Material de estudio basado en las prácticas de clase. Alcance confirmado: **terminal, GitHub Actions con YAML, `.gitignore` y GitHub Pages/despliegues**.

## Índice

1. [Terminal y Git](01-terminal-git.md)
2. [Archivo .gitignore](02-gitignore.md)

5. [GitHub Pages y despliegues](05-pages-despliegues.md)

## Cómo estudiar

1. Practica los comandos de terminal sin copiar.
2. Escribe desde cero la estructura de un workflow.
3. Practica los patrones de `.gitignore`.
4. Publica una web sencilla con `index.html`.
5. Comprueba que sabes localizar errores de indentación, rutas, nombres de ramas y dependencias.

**Nota:** en el examen, respeta las versiones de acciones y los nombres de ramas que indique el enunciado.
